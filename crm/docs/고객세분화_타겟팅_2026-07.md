## 3. 핵심 USP: 자차·자손 보험 — “불안한 사람”을 위한 타겟팅
국내 렌탈 바이크에서 보기 드문 자차·자손 보험 적용. 다쳐도(자손)·부숴도(자차) 안심하고 탈 수 있다. 경쟁 렌탈샵은 보험 미적용 — 이것이 아르테파인의 가장 강력한 차별점이다.
바이크를 타고 싶지만 실행하지 못하는 사람들의 공통 이유는 ‘불안’이다. 다칠까 봐, 부술까 봐, 물어줄까 봐. 따라서 보험은 부가 혜택이 아니라, 불안해서 망설이는 세그먼트의 진입 장벽을 제거하는 핵심 후킹 포인트다. 원칙은 단순하다 — 누가 불안해하는지 찾고, 그 사람에게 보험을 어필한다.
| 불안해하는 세그먼트 | 불안 요인 (진짜 망설이는 이유) | 보험 어필 메시지 / 콘텐츠 |
|---|---|---|
| 장롱면허·입문자 | “넘어지면 어떡하지. 남의 바이크를 부수면 물어줘야 하나.” | “넘어져도 괜찮습니다. 자차·자손 보험이 적용되니까요.” — 첫 라이딩 두려움 콘텐츠에 고정 삽입. [파손 보험 : 아카데미에도 활용] |

## 6. “특별한 경험” 이벤트 캠페인 상세
‘특별한 경험을 원한다’ 그룹은 라이딩 자체보다 기념일·인증·추억을 사는 고객이다. 따라서 렌탈 단품이 아니라 ‘이벤트 패키지’ 형태로 상품화한다.
| 패키지 | 구성 | 운영·판매 포인트 |
|---|---|---|
| ① 커플 라이딩 데이트 | 2시간 텐덤(2인 승차) 렌탈 + 출발 전 안전 브리핑. / 포토 스팟 코스 지도(한강·남산 야경 등). / 반납 후 폴라로이드 기념사진 1장. | 금·토 저녁 슬롯 한정으로 희소성 확보. / “주말 데이트 뭐 하지?” 타이밍인 수~목에 릴스 노출. |
| ② 웨딩 라이딩 촬영 | 클래식·레트로 감성 기종 지정. / 촬영 시간 보장(1시간 정차 촬영 허용) / 바이크 촬영용 대여, 렌탈. | 셀프 웨딩 촬영 트렌드와 결합. / 웨딩·스드메 카페에 후기 형태로 시딩. / 이용 커플 사진(동의 후) 콘텐츠화 → 자체 확산. |
| ③ 모토캠핑 원정대 | 슈퍼커브 캠핑 사양 + 사이드백·적재 장비 대여. / 근교 캠핑장 추천 코스(1박 왕복) 묶음. | 캠핑장 협업 또는 슈퍼커브모임에 / 아르테파인 슈퍼커브 렌탈 활용 |
| ④ Ride Seoul 투어 | 반나절 가이드 라이딩 투어(영문 브리핑 + 가이드 동행). / 한강~시내 코스 + 기념 사진. / “Fully insured” 보험 완비 강조. | 렌탈 단품이 아닌 투어 상품으로 판매 — 렌탈비의 1.5~2배 책정. / 에어비앤비 체험·클룩·트리플 등 여행 플랫폼 등록이 핵심. / 경쟁 상품이 사실상 없음. |
| ⑤ 인생샷 보장 코스 | 시간대별 촬영 스팟 지도(일출 한강, 야경 남산 등). / 감성 기종 지정 렌탈. / 월간 ‘이달의 인증샷’ 콘테스트(우승자 다음 렌탈 무료). | 콘테스트는 비용이 거의 없이 매월 UGC가 쌓이는 구조. / ‘돈 안 쓰는 마케팅’ 원칙에 가장 부합. / 수상작은 공식 계정·홍보물에 재활용. |
| ⑥ 부자(父子) 첫 라이딩 | 기초 안전 교육 30분 + 각자 기종 렌탈(아버지 클래식·아들 입문 기종). / 동반 주행 + 기념사진 액자 증정. | 5월 가정의 달·아버지 생신 수요 겨냥. / ‘선물하기 이용권’ 형태 판매 — 구매자(아들)와 이용자(아버지)가 달라 신규 고객 자동 유입. |
