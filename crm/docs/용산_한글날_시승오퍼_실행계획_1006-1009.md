- 범위: 용산 20대. 예상은 10/11(일)까지, 할 일은 10/6(화)~10/9(금).
- 오퍼: 시승 할인 "한글날엔 한 시간 더" 하나 + 기존 평일 40% 코드(`week-1001`). 연박 패키지는 하지 않는다.
- 채널: 회원 문자 2회(단골 포함), 인스타·스레드, 커뮤니티, 광고 최소안(약 45만원). **현장 직원의 단골 직접 연락은 하지 않는다.**

## 1. 오퍼 — "한글날엔 한 시간 더"

**3시간 이상 시승하면 1시간 무료.** 3시간 타고 2시간 값만 낸다.

| 이용 | 정가 | 오퍼 적용 | 체감 할인 |
|---|---|---|---|
| 3시간 | 69,000 | **46,000** | 33% |
| 4시간 | 92,000 | 69,000 | 25% |
| 5시간 | 115,000 | 92,000 | 20% |
| 24시간 렌탈 | 하루 요금 | 1시간분만 빠짐 | 작음 |

**왜 '시간' 할인인가**
- 할인 유형이 '시간'과 '퍼센트'뿐이다. 퍼센트는 최대 예약시간을 걸 수 없어서 24시간 렌탈까지 같은 %로 깎인다.
- '1시간'으로 걸면 짧은 시승에서는 크게, 긴 렌탈에서는 작게 깎인다.
- 최소 3시간으로 묶어 1~2시간 손님을 3시간으로 끌어올린다. 1시간 시승은 건당 2.5만원, 3시간은 이 오퍼로 4.6만원이다.
- "한글날엔 **한** 시간 더" — 한글의 '한'과 한 시간의 '한'을 겹친 말장난이라 기억에 남는다.

**할인 신청 입력값**

| 칸 | 입력 |
|---|---|
| 적용 지점 | 아르테파인 용산 라운지 |
| 할인명 | 한글날엔 한 시간 더 |
| 할인 유형 | **시간** · 1시간 |
| 제공 방식 | **전용 링크로만** |
| 전용 링크 코드 | **hour-1009** (다른 코드로 만들면 아래 모든 링크의 `promo=` 뒤만 바꾼다) |
| 최소 예약시간 | **3** |
| 회원별 일일 사용 한도 | **1** |
| 시작일시 | 2026-10-07 00:00 (시승 시작일 기준) |
| 종료일시 | 2026-10-11 23:59 |
| 고객 안내 문구 | 한글날 연휴 기념, 3시간 이상 시승하면 1시간 무료. 10/7(수)~10/11(일) 시승분, 1인 1일 1회. 다른 할인과 중복되지 않습니다. |

**기존 코드:** `week-1001`(평일 24시간 이상 40%, 10/6~10/8)은 그대로 둔다. 평일 하루 대여는 40% 코드, 시승은 한 시간 더.

**등록 직후 테스트 (10/6 오늘):**
1. 전용 링크로 3시간 예약 → 46,000원인지
2. 24시간 예약 → 얼마가 빠지는지(1시간 시승가 23,000원인지, 하루 요금의 1/24인지)
3. 2시간 예약 → 할인이 안 붙는지

## 3. 가동률·매출 예상 (용산, 10/5~10/11)

### 3-1. 전제

- **기본(아무것도 안 함):** 주간예측 리포트의 용산 일별 예측. 10/9(금)는 공휴일이라 일요일 수준(98만원)으로 올렸다.
- **오퍼·채널 효과:** 9/4 '2시간 무료' 문자 실측(용산 야간 경험 8.6%, 최근 90일 이용 4.4%, 동의 신규 1.8%, 9일간)을 이번 4일 창에 맞춰 절반쯤으로 낮췄다. 단골 직접 연락은 하지 않으므로 넣지 않았다.
- **할인 손실:** 오퍼가 없어도 왔을 손님이 코드를 쓰면서 깎이는 금액을 뺐다.
- **가동률 = 대여 시간 합 ÷ (20대 × 24시간).** 매출은 실측 평균(1시간당 약 11,400원)으로, 오퍼로 늘어나는 3~4시간 시승은 1시간당 약 15,000원으로 시간 환산했다. 영업시간(10~24시, 14시간) 기준도 함께 적었다.
