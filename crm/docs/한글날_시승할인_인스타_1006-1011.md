## 1. 한글날 시승 할인 — "10월 9일이니까 10,090원"

### 1-1. 왜 정액(원) 할인인가

할인 신청 화면에는 **최소 예약시간만 있고 최대 예약시간이 없다.** 퍼센트 할인을 걸면 24~72시간 렌탈에도 같은 %가 들어간다. 그러면 연박 패키지(5~25%)보다 더 싸지거나 패키지 대신 코드를 쓰게 된다.

**정액 할인은 짧게 탈수록 크게, 길게 탈수록 작게 느껴진다.** 그래서 시승에만 매력적이다.

| 이용 | 정가 | 10,090원 할인 후 | 체감 할인 | 패키지와 비교 |
|---|---|---|---|---|
| 2시간 시승 | 46,000 | **35,910** | 22% | 시승만 해당 |
| 3시간 시승 | 69,000 | 58,910 | 15% | 시승만 해당 |
| 4시간 시승 | 92,000 | 81,910 | 11% | 시승만 해당 |
| 24시간 (Rebel 500) | 150,000 | 139,910 | 6.7% | 패키지 5%와 비슷함 → 새는 돈 거의 없음 |
| 48시간 이상 | 300,000~ | — | 3% 이하 | 패키지 15~25%가 훨씬 유리 → 고객이 알아서 패키지를 고른다 |

### 1-2. 할인 신청 입력값

| 칸 | 입력 |
|---|---|
| 적용 지점 | 아르테파인 용산 라운지만 |
| 할인명 | 한글날 시승 10,090원 할인 |
| 할인 유형 | **정액 할인** (드롭다운에 있으면) · 10,090원 |
| 제공 방식 | **전용 링크로만** — 인스타 프로필 링크·스토리 링크·문자로만 배포. 링크별 유입이 방문통계에 잡힌다 |
| 최소 예약시간 | **2** |
| 회원별 일일 사용 한도 | **1** |
| 시작일시 | 2026-10-08 00:00 (시승 시작일 기준) |
| 종료일시 | 2026-10-11 23:59 |
| 고객 안내 문구 | 한글날(10월 9일) 기념 시승 10,090원 할인. 2시간 이상 시승, 10/8(목)~10/11(일) 시승분, 1인 1일 1회. 24시간 이상 대여는 연박 패키지 할인이 더 유리합니다. 다른 할인·패키지와 중복되지 않습니다. |

**정액 할인이 없고 퍼센트만 있다면:** **10%**, 최소 예약시간 2로 설정한다. 24시간 렌탈에서 패키지 1박(5%)보다 5%p 더 빠지지만, 48시간 이상은 패키지(15~25%)가 더 커서 고객이 패키지를 고른다. 이 경우 인스타 카드의 큰 숫자를 "10%"로 바꿔야 한다(`designs/hangul-1009/ig-ride.html` 수정 → `node render.js`).

### 1-3. 등록 후 확인

1. 전용 링크로 2시간 테스트 예약 → 결제 화면에서 35,910원인지
2. 같은 링크로 72시간 예약 → 패키지(20%)와 코드 중 무엇이 적용되는지. **코드가 적용되면** 안내 문구의 "24시간 이상은 패키지가 유리" 문장을 결제 화면에서 꼭 보이게 둔다.
3. 연휴 시승 슬롯이 꽉 차면(금·토 오후) 링크 배포를 멈춘다. 할인은 빈 시간을 채우는 용도다.
