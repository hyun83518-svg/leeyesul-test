# 아르테파인 CRM 데이터 작업 공간

## 구조

```
crm/
├── data/raw/            # 원본 내보내기 파일 (개인정보 포함, git 미추적)
├── scripts/build_crm.py # 정규화 → 중복 식별 → 리드 스코어 → 세그먼트 → 출력
├── output/
│   ├── CRM_마스터_<기준일>.xlsx   # 회원 마스터 + 세그먼트별 시트 (개인정보 포함, git 미추적)
│   ├── summary.json              # 집계 요약 (개인정보 없음)
│   └── 분석요약.md               # 집계 요약 마크다운 (개인정보 없음)
├── CRM_액션플랜.md      # 분석 결과 기반 마케팅 실행 계획
└── README.md
```

## 실행

```bash
pip install pandas openpyxl
python3 crm/scripts/build_crm.py            # raw/ 의 최신 '*전체*.xlsx' 사용
python3 crm/scripts/build_crm.py --master crm/data/raw/회원설문_2026-09-01_전체.xlsx
```

## 새 데이터가 들어올 때

1. 회원 설문 내보내기(같은 25개 컬럼)는 `crm/data/raw/회원설문_<날짜>_전체.xlsx` 로 저장 후 재실행.
2. 예약/렌탈/결제 등 다른 형태의 파일은 `build_crm.py`의 `load_extra_sources()`에 로더를 추가하고, 이메일 또는 정규화 연락처(`연락처_정규화`)를 키로 마스터에 병합한다.
3. 세그먼트를 추가·수정하려면 `SEGMENT_DEFS` 리스트에 (코드, 이름, 설명, 필터) 항목을 추가한다.
