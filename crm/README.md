# 아르테파인 CRM 데이터 작업 공간

## 구조

```
crm/
├── data/raw/            # 원본 내보내기 파일 (개인정보 포함, git 미추적)
├── scripts/build_crm.py # 정규화 → 회원관리·RCA·결제·예약이력·발송명단 병합 → 생애단계·VIP → 세그먼트·페르소나 → 발송 전환 대조 → 출력
├── output/
│   ├── CRM_마스터_<기준일>.xlsx   # 회원 마스터 + 세그먼트·페르소나·RCA·발송 시트 (개인정보 포함, git 미추적)
│   ├── CRM_타겟통합_<기준일>.xlsx # 타겟별 통합본: 0_요약 카탈로그 + 우선순위 A/B/C/X 타겟 시트 + 제외명단·캠페인성과·발송이력·라인업
│   ├── summary.json              # 집계 요약 (개인정보 없음)
│   └── 분석요약.md               # 집계 요약 마크다운 (개인정보 없음)
├── docs/                # 전략 문서(docx → md 변환본)
├── CRM_액션플랜.md      # 분석 결과 기반 마케팅 실행 계획
├── 전략문서_데이터매핑.md # 전략 문서 페르소나 ↔ 보유 데이터 매핑, 부족 데이터 목록
└── README.md
```

## 실행

```bash
pip install pandas openpyxl
python3 crm/scripts/build_crm.py            # raw/ 의 최신 '*전체*.xlsx' 사용
python3 crm/scripts/build_crm.py --master crm/data/raw/회원설문_2026-09-01_전체.xlsx
```

## 새 데이터가 들어올 때

1. 회원 설문 내보내기(같은 25개 컬럼)는 `crm/data/raw/회원설문_<날짜>_전체.xlsx` 로 저장 후 재실행. 가장 최신 날짜가 마스터가 되고, 나머지는 스냅샷 추이(7-1절)에 쓰인다.
2. 회원 관리 내보내기는 `crm/data/raw/회원관리_<날짜>_p<페이지>.xlsx` 로 저장하면 자동 병합된다(이메일 키).
3. 레인조 회원 DB는 `crm/data/raw/레인조_*.xlsx` 로 저장하면 연락처→이메일 순으로 매칭돼 RCA 컬럼과 R1/R2/R3 시트가 생긴다.
4. 결제 내역은 `crm/data/raw/결제내역_<날짜>_전체.xlsx`(시트 '결제상세')로 저장하면 자동 병합된다. 여러 파일을 두면 합쳐서 중복 제거한다. 새 차종은 `MODEL_INFO`에 장르·배기량대를 추가한다.
5. 그 외 다른 형태의 파일은 `build_crm.py`의 `load_extra_sources()`에 로더를 추가하고, 이메일 또는 정규화 연락처(`연락처_정규화`)를 키로 마스터에 병합한다.
6. 운영 정책 상수: `SEND_TO_UNASKED = True` 이면 설문 도입 전 가입한 마케팅 미응답자도 `발송가능`으로 본다(2026-09-13 결정). `RCA_HEAVY_MIN = 4` 는 R1 헤비 기준.
7. 문자 발송 명단은 `crm/data/raw/발송명단_<발송일>_<이름>.xlsx`로 저장하고 `load_send_log()`의 `meta`에 (발송일 → 캠페인 코드, 설명, 시트 목록, 홀드아웃 시트) 를 등록하면 전환 대조와 수신자 프로필에 포함된다. 시트에 `연락처` 컬럼만 있으면 된다.
8. 타겟 통합본의 타겟은 `TARGET_DEFS`(코드, 이름, 우선순위, 실측 근거, 권장 오퍼, 발송 시점, 필터)로 정의한다. 발송가능 필터가 자동 적용되고 X 타겟만 참고용.
9. 세그먼트를 추가·수정하려면 `SEGMENT_DEFS` 리스트에 (코드, 이름, 설명, 필터) 항목을 추가한다. 전략 문서 페르소나는 `PERSONA_DEFS`, 동기 그룹은 `MOTIVE_GROUPS`.
